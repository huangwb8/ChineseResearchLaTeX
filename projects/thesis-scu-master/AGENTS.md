# thesis-scu-master 项目指令

遵循根目录 `AGENTS.md`。本目录是四川大学硕士论文薄项目入口，学校样式统一维护于 `packages/bensz-thesis/` 的独立 `thesis-scu-master` profile/style，不改动其他学校的样式。

修改前阅读 `README.md` 与 `docs/specification.md`。后者记录法学院附件与高分子学院需求的适用差异及纸型、版心、标题的取舍；不要把示例写成学校官方认证或实测研究。

构建使用仓库官方 `thesis_project_tool.py` 或本项目 `scripts/thesis_build.py`。缓存只进入 `.latex-cache/`；最终示例为 `main.pdf`。不要将 DOCX 初稿宣称为正式 Word 排版成品。
