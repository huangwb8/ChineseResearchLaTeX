# 规范来源与取舍

本模板对应 [issue #56](https://github.com/huangwb8/ChineseResearchLaTeX/issues/56)，核对日期为2026年11月11日。需求填写的单位是四川大学高分子科学与工程学院，所附规范来自法学院；这里记录的是本次交付的依据与实现边界，不将其扩展为川大全校现行规范。

## 来源

- [附件4：论文格式规范](https://github.com/user-attachments/files/34691050/4.docx)：论文材料顺序、正文与摘要版式示意、目录及声明原文。关键版式要求嵌在图片中，不能仅通过 Word 文本提取获取。
- [附件5：封面参考模板](https://github.com/user-attachments/files/34691052/5.docx)：校名字样、封面字段、摘要示例；Word 页面约197.04×273.03 mm。
- [附件6：引注及参考文献](https://github.com/user-attachments/files/34691051/6.docx)：连续脚注、小五宋体、分类书目、类内作者排序和连续书目编号。
- [社区实现 scu_thesis_2020](https://github.com/kevinleeex/scu_thesis_2020) 及其 [文档类子模块](https://github.com/kevinleeex/scu_thesis_template)：参考材料组织与公开实现思路。其默认A4纸、双面开章和2020写作指南不直接适用于本次16开要求，未复制其GPL文档类或样式代码。

## 实现对照

| 项目 | 本模板的处理与依据 |
| --- | --- |
| 纸型 | 197×273 mm，采用附件5实际16开页面的毫米近似值；不沿用社区A4设置。打印采用实际大小，不缩放到A4。 |
| 版心 | 145×225 mm，来自附件4正文与摘要图。issue 的摘要“145×125 mm”与附图不符，采用图中225 mm；摘要正常跨页，不通过压缩字号强行塞入一页。 |
| 正文 | 小四宋体，固定20 bp（Word磅）基线距离，首行缩进2字，145 mm行宽约容纳34个全角汉字。混排、标点挤压与公式会影响实际每行字数。 |
| 标题 | 小三黑体、四号黑体、小四黑体、小四楷体，四级均左对齐。遵循issue的明确要求；附件图中前两级居中、后两级缩进的示例未采用。相邻标题不另空行，正文后标题前留一行。 |
| 摘要 | 中文题目小二宋体，专业小四宋体，身份标签小四黑体、姓名小四楷体，正文小四宋体，关键词标签小四黑体。标题上空两行、专业与姓名前各空一行、姓名后空两行。摘要标题为四号黑体。 |
| 图表 | 题名五号黑体，表格内容五号宋体；浮动体与正文留约一行。插图内部文字由作者按图形内容设置。 |
| 引注 | 按附件6连续阿拉伯数字上标脚注，小五宋体；参考文献五号宋体，显式分类与排序。重复引注和页码需要作者校核。 |
| 前后置材料 | 按附件4顺序：封面、中文摘要、英文摘要、目录、引言/正文/结论、参考文献、附录、致谢、科研成果、独创性声明与使用授权书。声明原文来自附件4，签名留空。 |
| 字体 | 默认Fandol宋/黑/楷及TeX Gyre Termes，便于跨平台和Overleaf稳定构建；它们分别是宋/黑/楷与Times风格的可用替代，不等同于Windows中宋体及Times New Roman的字形。精确字体提交要求需在有字体许可的环境核对。 |
| 页眉页码 | 采用附件4示意的“四川大学硕士学位论文”页眉、底部居中页码；封面无页码，前置材料罗马数字，正文阿拉伯数字；单面连续编排，不强制插入空白偶数页。 |
| Word | 附件要求Word排版，PDF工作稿与通用DOCX初稿不能证明Word提交合规。导出后仍须在Word中核对版式、脚注和完整性。 |

校名字样从附件5公开封面提取，仅用于该学校模板标识；不代表学校授权或认可本项目。原始DOCX与分析截图不随工程分发，避免携带文档编辑元数据和无关内容。示例正文与模型图为本项目新写，不复用社区示例中的论文数据。
