\chapter*{\rmfamily Abstract}
\pdfbookmark[0]{Abstract}{xmu-abstract-en}

Editing and re-encoding can change the frame-level features of a publicly available video. Using video clips of Nozomi Sasaki as an example, this report illustrates short-window feature pooling and similarity matching for duplicate clip retrieval. It describes how to split the dataset by source video to keep clips from the same source out of both tuning and evaluation. The appendix provides simulated features to illustrate the layout and calculation.

\medskip
\noindent\textbf{Keywords:} video retrieval, temporal features, similarity matching
