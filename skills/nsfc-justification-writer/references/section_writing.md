# 分节写法

立项依据沿 **临床需求 → 已有认识 → 研究局限 → 科学问题 → 科学假设** 逐步推进。基础、理论或方法学课题从相应的科学或应用需求出发。

研究意义、国内外研究现状、科学问题与科学假设、小结是常见的组织方式。依据论证需要决定如何分段和命名，能承载论证的原有标题和 LaTeX 结构予以保留。结构命令变化仍须遵守授权与脚本检查。

## 修订前诊断与修改范围

先明确任务类型、核心科学主张和论证主线，再决定修改幅度。重要发现列出位置、依据和影响，分为“必须修复、建议优化、可以保留”。“必须修复”表示问题影响事实、推理或理解，不代表可以越过科学主张的修订授权。

| 任务 | 修改范围 |
| --- | --- |
| 新写 | 从材料建立论证，缺失信息显式登记，候选假设标明推测性质。 |
| 重构 | 按论证需要重排、合并段落，说明重要调整如何改善证据关系，保持科学主张。 |
| 审查 | 只交付诊断与建议，不调用默认写入的 preview，也不创建正文文件。 |
| 润色 | 优先局部澄清、压缩重复和改善衔接，保留合理结构与作者声音，实质问题单列。 |

结构合理、表达准确时可以建议保留。诊断和生成可在一次执行中完成，无需逐阶段确认；这些类别不新增 CLI 子命令。

## 科学含义变化的处置

措辞调整和不改变科学关系的句段重排可直接完成，重要重排在总结中说明。改变因果方向、机制解释、研究对象、适用范围或核心假设时，先核对依据与已有授权；“证明”降为“提示”、“导致”改为“相关”也可能改变主张，不能仅因措辞更保守就自动替换。

依据明确且属于既有修订授权的纠错可以执行并解释。材料不足或未获相关授权时，只提出候选改法及影响，保留原文主张。若相关段落因此无法形成可信成稿，保留该段原文，完成其余可保真修订，标出未解决问题，不宣称全文已可直接使用。候选解释不等于作者采用；已有明确授权无需再次询问。

## 动笔前的最小输入

不需要单独填写信息表。先从项目正文、研究内容、研究基础和参考文献中提取以下五项；缺失项登记为待核验信息，不凭空补写：

- 研究对象与应用边界；
- 现有研究的关键瓶颈及其证据；
- 要解释的核心未知（可在正文中自然收束为问题）；
- 能解释该未知且可被证伪的科学假设；
- 本项目相对现有路线的切入点。

篇幅、术语和引用口径直接写在任务要求或项目配置中。脚本不再生成或读取 `info_form.md`。

## 动笔前：先画论证地图

先用几句话固定下列关系，再开始写段落：

| 要素 | 要回答的问题 |
| --- | --- |
| 研究对象与边界 | 研究什么，适用于什么场景，不讨论什么？ |
| 研究需求 | 为什么需要获得某项认识？它会改变对什么现象或判断的理解？ |
| 已有认识与局限 | 现有证据回答了什么？在什么条件下仍不足以解释与需求直接相关的现象？ |
| 证据 | 每个判断由哪类研究、数据或可追溯文献支持？ |
| 约束 | 哪些条件改变时，现有解释会失效或需要重新检验？ |
| 核心未知 | 现有证据究竟还不能解释哪一个关系、机制、性质或适用边界？ |
| 科学假设 | 哪项已有观察或理论依据使候选解释值得检验？若解释成立，应观察到什么？什么结果会削弱或推翻它？ |
| 项目切入点 | 相对现有路线新增了什么表征、框架、机制或方法学贡献？ |

先确认局限有证据支撑，核心未知可由该局限推出，候选解释的关键概念在前文已有来由。进一步核对假设是否正面回答该未知、其预测能否在后续研究中检验。材料支持多种解释时，保留影响主论证的竞争解释及其分歧。证据链有断点时按材料补足或登记缺口。这张表用于梳理推理，正文用连贯的段落呈现。

## 正文判断与审查记录分离

论证地图可以完整记录研究边界，但正文不需要逐项复述这张审查表。写作时先把主张放在段首，保留所有会改变科学解释的必要限定；多个必要条件可拆句或分段表达。只用于审查、不改变本段解释的证据等级、外推风险及待核验项归入交付说明，不能仅因它们属于“边界”就移出正文。

使用以下取舍顺序：

1. **保留改变解释的限定**：例如“关系在跨中心、平台和人群中的重复性”需要说明适用条件，或“表征稳定性不等于临床获益”需要保留这一真实二分。
2. **合并同义限定**：同一段连续出现“不能证明、不等同于、仍需独立验证”时，合并为一条与本段判断直接相关的范围说明。
3. **移出审查信息**：证据等级、外推边界和“本项目不负责”的责任切割若不改变本段解释，记录在审查字段，不写成正文主体句。
4. **缺证据时标明缺口**：新写主张限定在材料支持范围；修订原稿按科学含义变化边界处置，证据明确且获授权时才纠正强度，否则保留待决段落并给建议。不用更多否定句遮盖资料缺口。

## 研究意义

### 这一节的任务

研究意义通常是立项依据的第一小节，回答“为什么需要这项研究、还缺什么认识”。这里突出一个总的认识缺口，建立需求与科学价值的联系；完整的核心科学问题留到研究现状之后，结合证据正式提出。研究意义不是研究方案的提前摘要。

### 从需求到认识缺口

研究意义常可用两段分别交代需求和认识缺口。两者的关系紧密时可以合写，解释需要更多证据时可分段展开。

1. **研究需求：为什么需要**。界定研究对象、关键现象或应用场景，用可核验事实说明其科学、临床、社会或工程影响，以及现有认识或实践为何难以满足需求。段末落在需要获得何种认识及其价值，为下一段留下推进空间。
2. **认识缺口：还缺什么认识**。承接这一需求，概括已有解释的贡献与不足，聚焦一个总的认识缺口，说明它如何限制对对象的理解，以及弥补它的科学价值；具体证据与路线比较交给研究现状展开。

如果两段都以“亟待解决的重要问题”收束，检查后段是否说明前一项需求为何受同一个认识缺口制约。把这层关系交代清楚，读者就能理解现状部分为何集中讨论这个缺口。

### 写作取舍

- 理论导向优先写：假设过强、因果机制不明、表征不足、框架不统一、理论界不紧。
- 工程或应用导向可以从需求和代价切入，但要尽快落到科学约束和可回答的问题。
- 不在这里展开模型结构、平台搭建、技术路线、主终点、阈值、统计规则或风险处理。
- “重大意义”“关键作用”等判断必须落到对象、影响范围、对照或可核验事实。

## 国内外研究现状

### 先分路线，再写文献

按与核心问题有关的解释分歧或证据缺口综合文献。可以比较：

- 不同理论解释或机制假说；
- 不同测量、建模或验证路线；
- 不同研究对象、尺度或应用条件；
- 观察性证据、机制性证据和干预性证据。

各主题的详略取决于它对科学问题的贡献。确需小标题时，用该组研究解决的具体问题命名。

### 公允比较与缺口分类

先交代已有工作解决了什么及其贡献，再讨论与本项目直接相关的限制。按证据区分三类缺口：已考察但尚未解决；材料中尚未研究或缺少评价；在明确假设、理论条件下不能解决。未经评价不意味着做不到，条件内的结论不能推广为普遍不可能。

“未找到相关报道”只说明已读取材料的覆盖情况，不能直接写成“首次”或“领域空白”。材料不足时登记待核验内容，不把局部文献当作全领域证据。比较路线应尽量统一研究对象与评价条件，避免贬低前人来放大项目空间。

性能改善与科学贡献分别说明。计算、理论和方法学项目可以研究可识别性、收敛性质、误差界、表征规律及泛化条件，无需套成生物机制。

### 综合代表性证据

先判断这些研究共同支持什么、分歧出在哪里。写清足以改变结论的条件，再沿这个差异组织文献。如果测量条件或对象差异足以解释结论不一致，交代具体差异及依据。如果现有材料无法判断分歧缘由，把这一点保留为证据缺口。

### 比较研究路线时看什么

不要只比较“准确率更高”或“性能更好”，至少从下列维度中选与课题相关的几项：

- 研究对象、数据来源和适用边界；
- 核心假设及其是否足够弱；
- 能解释的机制或可识别的关系；
- 证据类型：观察、相关、机制、干预或外部验证；
- 对照、基线、样本规模和不确定性；
- 稳健性、可迁移性、可重复性和理论保证。

方法术语应服务于科学判断；方法学项目可用必要的方法概念组织论证，但须解释其性质、成立条件和仍未解决的问题。

### 证据与引用技巧

- 一条引用只承担它实际支持的主张；不要让一个 bibkey 覆盖一串未经区分的结论。
- 区分“已观察到”“相关”“提示机制”“已经证明”；修订既有主张时按科学含义变化边界处理，不自动把因果改成相关。
- 代表性工作不等于逐篇摘要。优先综合共同结论、分歧和边界，再列必要引用。
- 文献不足时登记覆盖与支持性缺口，限定新写主张；原稿实质变化按授权处置，不虚构新文献填补空缺。

### 主题之间的衔接

后一个主题可以补充前一类证据未覆盖的条件、引入竞争解释，或共同指向同一个未知。把实际的承接关系写出来。若某个主题无法为核心问题提供证据、前提或边界，缩短或移出主线。

## 科学问题与科学假设

本节紧接研究现状、位于小结之前。它不是研究方案的压缩版，而是把“研究现状中的不足”讲成一条有因果关系的叙述：已有认识推进到哪里，哪一个关键关系仍未解释，为什么这个未知值得单独提出，以及本项目的切入点为何能形成可证伪的预测。科学问题可以在段末用疑问句明确收束，也可以先用连续叙述铺垫后再明确点出；科学假设随后解释预期机制或关系，不要求另起编号列表。

### 瓶颈 → 约束 → 问题 → 假设

这是内部构思工具，不是成稿模板。先用它检查逻辑，再把映射改写成连贯段落；不要把下面的标签、序号或箭头直接交给读者：

```text
瓶颈 1：现有解释依赖条件 A
约束 1：在条件 A 受限时
瓶颈 2：机制 B 缺少因果证据
约束 2：在机制 B 未明确时
核心未知：在约束 1、2 下，X 的 Y 性质为何、何时能够保持？
科学问题：在什么条件下，X 的 Y 性质能够跨越约束 1、2 保持，并由何种关系解释？
科学假设：如果机制 P 是关键限制，那么引入与 P 对应的表征/切入点后，X 将在约束 1、2 下呈现可观察的 Y 关系；这里的 Y 若指表征稳定性，不延伸为临床获益。
```

### 叙事优先的写法

成熟的立项依据通常不是把问题拆成多个编号任务，而是让读者先理解“为什么现有认识还不够”。可以按下面的顺序写成一个或两个自然段：

1. 回收研究现状中最重要的共同认识，并指出它在哪个条件变化后失去解释力；
2. 说明这个缺口造成的科学后果，避免直接跳到“本项目将检验……”；
3. 用一个核心问题把未知关系、机制或边界说清楚；若确有两个不可合并的未知，说明二者的因果或依赖关系，不要只并列编号；
4. 从项目切入点解释假设为何合理，再给出一个可以被支持或推翻的预测；模型、数据划分和评价指标只保留会改变科学解释的最少信息，详细方案后置。

例如，不要写成：

```text
R1：检验结构稳定性；R2：检验外部一致性；R3：检验新样本外推。
H1：模型在留出队列达到指标 A；H2：方法 B 优于方法 C；并进行折叠、调参和敏感性分析。
```

可以改写为：

```text
现有研究能够在生成队列中描述样本关系，却尚不能说明这些关系在队列构成和观测平台改变后是否仍代表同一生物学状态。真正需要回答的不是某一种模型能否复现原有标签，而是哪些关系具有跨队列的可重复性，以及这种重复性在什么条件下可以外推到新样本。基于这一缺口，本项目提出：若相对关系确实承载了比绝对表达尺度更稳定的生物学信息，那么以该关系为基础构建的表征应能在外部队列中保持与独立生物学参照一致的结构；若这一预测不成立，则可据此界定其适用边界。
```

这类写法仍然可证伪，但把“未知—理由—切入点—预测”交代完整，读者看到的是科学判断而不是验收协议。

叙述的深度来自解释现有证据之间的张力，而不是增加术语、任务或指标。至少要说清：已有结果在哪个条件下成立；条件改变后，哪一种解释会失效或彼此难以区分；项目切入点提供了什么新的观察角度；若假设成立，认识会推进到哪里。只有相关性材料时，新写可以提出有边界的机制候选及其待验证预测，不能把候选写成已确立结论；修订原稿仍须核对科学主张授权。

### 前期材料如何参与推导

先区分三种作用：支持假设的观察、支持实施可行性的基础、仍待验证的探索性线索。参与假设推导的关键观察应在提出假设之前或紧邻假设交代，并标明来自外部文献还是申请团队；不把文献结果写成团队成果，也不把探索性结果当作确认。

实施基础仅简短衔接研究基础章节，平台、模型细节不替代假设依据。没有团队前期结果时，可依据已核验文献形成有边界的假设并登记支持不足，不强加“前期基础”段落。小结只回收已经参与论证的要点，避免假设先出现、关键观察到文末才首次出现。

### 科学问题的判定

好的科学问题：

- 指向明确的认知缺口，而不是泛泛问“如何提高性能”；
- 追问是什么、为什么、遵循什么规律或在什么条件下成立；
- 能由研究设计回答，答案又不是显然的；
- 问题中的约束都在前文出现过，术语与全文一致。

推荐句式（按材料改写，不要机械套用）：

- 在约束 A、B、C 下，X 的 Y 性质为何能够/不能保持？
- 什么条件下 X 的 Y 性质成立？
- 条件 A 变化时，X 的 Y 是否稳定、可迁移或可泛化？
- 现有证据所揭示的 X—Y 关系，是否代表同一机制，还是由条件 A 诱导的表面相关？

避免把问题写成“R1/R2/R3”“本项目依次检验……”或“能否构建/开发/实现 XXX”“本项目拟建立 XXX 以达到 XXX”；前两类是验证协议，后两类是研究目标或工程任务。

### 科学假设的判定

假设使用陈述句，解释“为什么会这样”并预测“将是什么或会发生什么”，不要把验证方式写进句子。可用：

```text
[核心机制/表征] 是 [现象/关系] 在约束 [A] 下仍能保持的原因；因此，引入 [切入点] 后，
[对象] 将呈现 [可观察、可反驳的关系或性质]。
```

写完后逐项检查：问题是否由前文缺口推导出来？假设是否解释了问题而不是重复项目目标？预测是否能被材料允许的观察推翻？是否把“在外部队列中验证”“通过实验验证”、模型结构、折叠和指标误写成假设本身？除非研究确实包含彼此独立的机制分支，不要把假设编号为 H1/H2。

理论、混合和工程导向只改变证据重心：理论项目强调定理、界、收敛性、反例或统一框架；机制项目强调因果链和跨尺度表征；工程项目强调约束、基线、指标和迁移边界，但都要保留可证伪的问题—假设关系。

## 小结

需要小结时，简要说明已有认识把研究推进到哪里、本项目还能澄清什么，再衔接研究内容。推导假设所需的关键观察应已在前文交代。

切入点应写成相对现有工作的实质增量，例如新表征、新机制、新方法学、统一框架或可证明理论。软件、平台和原型可以作为实现载体，但不要替代理论或科学贡献。详细目标、技术路线、主验证场景、判定规则和风险处理放到后续章节。

## 段落和句子的实用技巧

### 每段推进一个主要判断

用一句话概括每段带来的新判断，并检查它是否承接前文已交代的事实或疑问。前后两段承担同一任务时可以合并。离开该段仍能完整推出核心问题或假设时，检查该段是否提供必要背景、证据或限定，否则压缩或移到相应章节。研究现状可按“主张 → 证据 → 解释 → 缺口”推进，段尾依据论证作用承接下文。

### 已有证据、合理推论与待验证假设

- 已有证据写明直接观察到的结果、来源及影响解释的条件。
- 合理推论交代由何种观察推出、依赖什么前提。措辞随证据强度调整，可靠发现可以明确陈述。
- 待验证假设给出针对核心未知的候选解释、可观察预测及能使该解释站不住脚的结果。

同一句包含观察和解释时，用清楚的主谓关系或分句表明两者的推导关系。尤其要检查相关性是否被写成因果，初步观察是否被写成机制结论，以及项目预期能回答的问题是否被写成已经取得的发现。

### 用可比较的语言替代空泛评价

比较性能时写清比较对象、适用条件、指标和有依据的结果。说明研究价值时写清项目能够澄清的关系、机制、性质或适用边界。涉及创新时指出相对已有工作的实质增量。临床影响按证据及项目能回答的范围陈述，假设尚待验证时可说明不同结果各能澄清什么。

### 保持术语和指代稳定

对象名称、缩写、指标和“该机制/这一现象”的指代应前后一致。首次出现的新概念给出最小界定；一句话中不要连续堆叠多个抽象名词。润色时保留事实、限定、引用、标签和 LaTeX 结构。

### 段落之间承接事实或问题

段落之间用具体的事实或问题承接。删掉“因此”“综上”等连接词后，若两段的关系仍说不清，补出推理前提、调整顺序或删压无关内容。术语和句式以同领域评审可准确理解为准，优先拆开堆叠的判断与限定。
