# 分节写法

立项依据不是四段并列的背景介绍，而是一条逐步收紧的论证链：

> **为什么值得做 → 已有研究做到哪里 → 为什么仍不够 → 真正要回答什么 → 本项目从哪里切入**

默认内容顺序为：**研究意义 → 国内外研究现状 → 科学问题与科学假设 → 小结**。主题性小标题只嵌套在“国内外研究现状”内。

## 动笔前的最小输入

不需要单独填写信息表。先从项目正文、研究内容、研究基础和参考文献中提取以下五项；缺失项保留为待核验假设，不凭空补写：

- 研究对象与应用边界；
- 现有研究的关键瓶颈及其证据；
- 要解释的科学问题（疑问句）；
- 可证伪的科学假设（预测性陈述）；
- 本项目相对现有路线的切入点。

篇幅、术语和引用口径直接写在任务要求或项目配置中。脚本不再生成或读取 `info_form.md`。

## 动笔前：先画论证地图

先用几句话固定下列关系，再开始写段落：

| 要素 | 要回答的问题 |
| --- | --- |
| 研究对象与边界 | 研究什么，适用于什么场景，不讨论什么？ |
| 一句话问题定义 | 评审能否用一句话听懂“现在卡在哪里”？ |
| 关键瓶颈 | 现有研究的 2–4 个具体障碍是什么？ |
| 证据 | 每个判断由哪类研究、数据或可追溯文献支持？ |
| 约束 | 每个瓶颈在科学问题中对应什么前提或限制？ |
| 科学问题 | 要解释的未知关系、机制、性质或适用条件是什么？ |
| 科学假设 | 通过什么策略可得到什么可证伪结果？ |
| 项目切入点 | 相对现有路线新增了什么表征、框架、机制或方法学贡献？ |

关键瓶颈必须能在前文找到依据；科学问题不能凭空增加约束；假设中的关键策略必须能在后续研究内容中落地。

## 1. 研究意义

### 这一节的任务

回答“为什么值得研究”，建立研究对象的重要性、现有认识的不足和解决缺口的科学价值。研究意义不是研究方案的提前摘要。

### 推荐的段落推进

通常写 2–3 段，约占全文 15%–25%。每段只承担一个相邻功能：

1. **对象与重要性**：界定研究对象、关键现象或应用场景，说明其科学、临床、社会或工程影响。
2. **认识与理论缺口**：指出已有解释、框架或路线在哪些条件下失效，造成什么认知后果。
3. **研究价值与承接**：说明解决该缺口将带来什么可推广的认识或方法学价值，并自然引向研究现状。

常用推进句式：

```text
研究对象 X 关系到 Y，但在 Z 场景下仍缺乏稳定/统一的解释。
现有研究虽然揭示了 A，却受 B、C 约束，尚不能回答 D。
因此，有必要围绕 D 重新审视 X，并为后续科学问题提供依据。
```

### 写作取舍

- 理论导向优先写：假设过强、因果机制不明、表征不足、框架不统一、理论界不紧。
- 工程或应用导向可以从需求和代价切入，但要尽快落到科学约束和可回答的问题。
- 不在这里展开模型结构、平台搭建、技术路线、主终点、阈值、统计规则或风险处理。
- “重大意义”“关键作用”等判断必须落到对象、影响范围、对照或可核验事实。

## 2. 国内外研究现状

### 先分路线，再写文献

按“研究问题、核心假设或证据类型”分成 2–4 个主题，而不是按年份或作者流水账罗列。常见分类方式包括：

- 不同理论解释或机制假说；
- 不同测量、建模或验证路线；
- 不同研究对象、尺度或应用条件；
- 观察性证据、机制性证据和干预性证据。

每个主题通常 1 段，必要时最多 2 段。主题名称应能说明这一组工作解决什么问题，不要只写“方法一、方法二”。

### 一个主题段落的内部结构

每个主题按以下顺序压缩：

1. **主题句**：这一方向试图解决什么问题，代表性路线是什么。
2. **代表证据**：概括最能支撑判断的工作、数据或结果，引用紧跟相应主张。
3. **进展与边界**：说明已经获得什么认识，以及结论在哪些条件下成立。
4. **关键缺口**：指出仍未解释的关系、机制、性质或适用边界，为下一节问题铺垫。

可用的段落骨架：

```text
现有研究主要沿 A、B 两条路线展开。A 路线在条件 C 下说明了……，但依赖……；B 路线能够……，却难以解释……。因此，当前缺口不是“方法不够多”，而是……尚未被统一解释/验证。
```

### 比较研究路线时看什么

不要只比较“准确率更高”或“性能更好”，至少从下列维度中选与课题相关的几项：

- 研究对象、数据来源和适用边界；
- 核心假设及其是否足够弱；
- 能解释的机制或可识别的关系；
- 证据类型：观察、相关、机制、干预或外部验证；
- 对照、基线、样本规模和不确定性；
- 稳健性、可迁移性、可重复性和理论保证。

方法术语可以作为现状证据出现，但不能成为段落主线。删除方法名称后，段落仍应保留“现象—证据—局限—缺口”的科学判断。

### 证据与引用技巧

- 一条引用只承担它实际支持的主张；不要让一个 bibkey 覆盖一串未经区分的结论。
- 区分“已观察到”“相关”“提示机制”“已经证明”；证据强度不足时降低措辞强度。
- 代表性工作不等于逐篇摘要。优先综合共同结论、分歧和边界，再列必要引用。
- 文献不足时缩小主张并记录待核验项，不用新文献填补叙事空缺。

### 主题之间的衔接

每个主题结尾应留下一个能被下一主题接住的缺口：

- “然而，该路线主要解决了……，尚未说明……”
- “这一结果提示……，但在……条件下仍缺乏证据。”
- “因此，下一步需要从……机制/边界重新考察……”

这样可以把多个主题写成一条研究脉络，而不是几个互不相干的文献摘要。

## 3. 科学问题与科学假设

本节紧接研究现状、位于小结之前。它负责把“研究现状中的不足”收束为可回答的认知问题，再给出对应的预测性假设。

### 瓶颈 → 约束 → 问题 → 假设

建议先列出一一映射，再写成正文：

```text
瓶颈 1：现有解释依赖条件 A
约束 1：在条件 A 受限时
瓶颈 2：机制 B 缺少因果证据
约束 2：在机制 B 未明确时
科学问题：在约束 1、2 下，X 是否仍具有 Y 性质？
科学假设：X 通过策略 P、Q 应对约束 1、2，可实现/保有 Y，并相对基准呈现可检验的增量。
```

### 科学问题的判定

好的科学问题：

- 指向明确的认知缺口，而不是泛泛问“如何提高性能”；
- 追问是什么、为什么、遵循什么规律或在什么条件下成立；
- 能由研究设计回答，答案又不是显然的；
- 问题中的约束都在前文出现过，术语与全文一致。

推荐句式：

- 在约束 A、B、C 下，X 是否仍保有 Y 性质？
- 什么条件下 X 的 Y 性质成立？
- 条件 A 变化时，X 的 Y 是否稳定、可迁移或可泛化？

避免“能否构建/开发/实现 XXX”“本项目拟建立 XXX 以达到 XXX”；这类句子描述研究目标或工程任务。

### 科学假设的判定

假设使用陈述句，预测“将是什么或会发生什么”，不要把验证方式写进句子。可用：

```text
[核心机制/表征] 通过 [应对关键约束的策略]，可 [预期结果]，
并相对 [对照/基准] 呈现 [增量价值、稳定性或泛化性]。
```

写完后逐项检查：问题中的每个关键约束是否都有对应策略？假设中的每个策略是否在研究内容中有实施位置？是否把“在外部队列中验证”“通过实验验证”等方法描述误写成假设本身？

理论、混合和工程导向只改变证据重心：理论项目强调定理、界、收敛性、反例或统一框架；机制项目强调因果链和跨尺度表征；工程项目强调约束、基线、指标和迁移边界，但都要保留可证伪的问题—假设关系。

## 4. 小结

小结通常用一段完成四步：

1. 压缩现状已经取得的主要认识；
2. 重申最关键的缺口和科学问题/假设；
3. 用与证据强度相称的方式放入前期工作，说明它为什么支持项目切入；
4. 用一句话衔接后续研究内容。

切入点应写成相对现有工作的实质增量，例如新表征、新机制、新方法学、统一框架或可证明理论。软件、平台和原型可以作为实现载体，但不要替代理论或科学贡献。详细目标、技术路线、主验证场景、判定规则和风险处理放到后续章节。

## 段落和句子的实用技巧

### 一个段落只推进一个判断

推荐使用“**主张 → 证据 → 解释 → 缺口**”四步。段首先告诉读者本段要判断什么，中间给证据和限定，段尾说明这组证据为什么仍不足。不要在同一段同时引入新对象、总结全文和提出项目方案。

### 事实、解释和推断分层

- 事实：已有研究观察到什么；
- 解释：这些结果支持哪种机制或理论；
- 推断：在什么边界内可以得出什么结论；
- 缺口：哪一步仍没有证据。

用“表明、提示、支持、尚不能说明、仅在……条件下成立”等词标出证据强度，避免把相关性写成因果性。

### 用可比较的语言替代空泛评价

把“效果好、明显提升、国际领先、填补空白”改成“相对谁、在什么对象/条件下、以什么指标、达到什么范围”。没有可靠数字时，写清适用范围、证据类型和未解决边界，不虚构量化结果。

### 保持术语和指代稳定

对象名称、缩写、指标和“该机制/这一现象”的指代应前后一致。首次出现的新概念给出最小界定；一句话中不要连续堆叠多个抽象名词。润色时保留事实、限定、引用、标签和 LaTeX 结构。

### 用过渡句显示研究脉络

段落之间明确“已有认识 → 新限制 → 下一问题”的关系；少用没有逻辑功能的“此外、同时、综上”。每个转折词都应能回答：是补充证据、比较路线、引出限制，还是收束到科学问题？

## 交稿前的五个评审问题

1. 开头是否在有限篇幅内说清研究对象、重要性和真正卡点？
2. 现状是否按问题或路线综合证据，而不是按作者和年份堆叠？
3. 每个关键瓶颈是否都映射到了科学问题的约束？
4. 科学假设是否给出可证伪的预测，并覆盖关键约束而没有写成验证方案？
5. 小结中的项目切入点是否体现实质科学增量，并自然引到后续研究内容？
