# 分节写法

立项依据不是四段并列的背景介绍，而是一条逐步收紧的论证链：

> **为什么值得做 → 已有研究做到哪里 → 为什么仍不够 → 真正要回答什么 → 本项目从哪里切入**

默认内容顺序为：**研究意义 → 国内外研究现状 → 科学问题与科学假设 → 小结**。主题性小标题只嵌套在“国内外研究现状”内。

## 动笔前的最小输入

不需要单独填写信息表。先从项目正文、研究内容、研究基础和参考文献中提取以下五项；缺失项保留为待核验假设，不凭空补写：

- 研究对象与应用边界；
- 现有研究的关键瓶颈及其证据；
- 要解释的核心未知（可在正文中自然收束为问题）；
- 能解释该未知且可被证伪的科学假设；
- 本项目相对现有路线的切入点。

篇幅、术语和引用口径直接写在任务要求或项目配置中。脚本不再生成或读取 `info_form.md`。

## 动笔前：先画论证地图

先用几句话固定下列关系，再开始写段落：

| 要素 | 要回答的问题 |
| --- | --- |
| 研究对象与边界 | 研究什么，适用于什么场景，不讨论什么？ |
| 一句话问题定义 | 评审能否用一句话听懂“现在卡在哪里”？ |
| 关键瓶颈 | 现有研究的 2–4 个具体障碍是什么？ |
| 证据 | 每个判断由哪类研究、数据或可追溯文献支持？ |
| 约束 | 哪些条件改变时，现有解释会失效或需要重新检验？ |
| 核心未知 | 现有证据究竟还不能解释哪一个关系、机制、性质或适用边界？ |
| 科学假设 | 哪个机制或表征能够解释这一未知，并产生什么可被证伪的预测？ |
| 项目切入点 | 相对现有路线新增了什么表征、框架、机制或方法学贡献？ |

关键瓶颈必须能在前文找到依据；核心未知不能凭空增加约束；假设中的机制或表征必须能在后续研究内容中落地。表格只服务于宿主 AI 的内部推理，成稿不应把它展开成“瓶颈 1—约束 1—R1—H1”的验收清单。

## 正文判断与审查记录分离

论证地图可以完整记录研究边界，但正文不需要逐项复述这张审查表。写作时先把主张放在段首，再选择一个会改变本段科学解释的关键限定；证据等级、临床外推边界、不能推出的下游结论和待核验项留在审查记录中。这样既保留证据强度，又不让审计清单打断研究脉络。

使用以下取舍顺序：

1. **保留改变解释的限定**：例如“关系在跨中心、平台和人群中的重复性”需要说明适用条件，或“表征稳定性不等于临床获益”需要保留这一真实二分。
2. **合并同义限定**：同一段连续出现“不能证明、不等同于、仍需独立验证”时，合并为一条与本段判断直接相关的范围说明。
3. **移出审查信息**：证据等级、外推边界和“本项目不负责”的责任切割若不改变本段解释，记录在审查字段，不写成正文主体句。
4. **缺证据时缩小主张**：把“证明”改为材料支持的“观察到、提示或支持”，并登记待核验项；不要用更多否定句来遮盖资料缺口。

## 1. 研究意义

### 这一节的任务

回答“为什么值得研究”，建立研究对象的重要性、现有认识的不足和解决缺口的科学价值。研究意义不是研究方案的提前摘要。

### 推荐的段落推进

通常写 2–3 段，约占全文 15%–25%。每段只承担一个相邻功能：

1. **对象与重要性**：界定研究对象、关键现象或应用场景，说明其科学、临床、社会或工程影响。
2. **认识与理论缺口**：指出已有解释、框架或路线在哪些条件下失效，造成什么认知后果。
3. **研究价值与承接**：说明解决该缺口将带来什么可推广的认识或方法学价值，并自然引向研究现状。

常用推进句式：

```text
研究对象 X 关系到 Y，在 Z 场景下仍缺乏稳定/统一的解释。
现有研究揭示了 A，但在 B 条件下尚未回答 D。
因此，有必要围绕 D 重新审视 X，并为后续科学问题提供依据。
```

### 写作取舍

- 理论导向优先写：假设过强、因果机制不明、表征不足、框架不统一、理论界不紧。
- 工程或应用导向可以从需求和代价切入，但要尽快落到科学约束和可回答的问题。
- 不在这里展开模型结构、平台搭建、技术路线、主终点、阈值、统计规则或风险处理。
- “重大意义”“关键作用”等判断必须落到对象、影响范围、对照或可核验事实。

## 2. 国内外研究现状

### 先分路线，再写文献

按“研究问题、核心假设或证据类型”分成 2–4 个主题，而不是按年份或作者流水账罗列。常见分类方式包括：

- 不同理论解释或机制假说；
- 不同测量、建模或验证路线；
- 不同研究对象、尺度或应用条件；
- 观察性证据、机制性证据和干预性证据。

每个主题通常 1 段，必要时最多 2 段。主题名称应能说明这一组工作解决什么问题，不要只写“方法一、方法二”。

### 一个主题段落的内部结构

每个主题按以下顺序压缩：

1. **主题句**：这一方向试图解决什么问题，代表性路线是什么。
2. **代表证据**：概括最能支撑判断的工作、数据或结果，引用紧跟相应主张。
3. **进展与边界**：说明已经获得什么认识，以及结论在哪些条件下成立。
4. **关键缺口**：指出仍未解释的关系、机制、性质或适用边界，为下一节问题铺垫。

可用的段落骨架：

```text
现有研究主要沿 A、B 两条路线展开。A 路线在条件 C 下说明了……，但在 D 条件下的适用性仍不清楚；B 路线补充了……，共同指向……尚未被统一解释/验证。
```

### 比较研究路线时看什么

不要只比较“准确率更高”或“性能更好”，至少从下列维度中选与课题相关的几项：

- 研究对象、数据来源和适用边界；
- 核心假设及其是否足够弱；
- 能解释的机制或可识别的关系；
- 证据类型：观察、相关、机制、干预或外部验证；
- 对照、基线、样本规模和不确定性；
- 稳健性、可迁移性、可重复性和理论保证。

方法术语可以作为现状证据出现，但不能成为段落主线。删除方法名称后，段落仍应保留“现象—证据—局限—缺口”的科学判断。

### 证据与引用技巧

- 一条引用只承担它实际支持的主张；不要让一个 bibkey 覆盖一串未经区分的结论。
- 区分“已观察到”“相关”“提示机制”“已经证明”；证据强度不足时降低措辞强度。
- 代表性工作不等于逐篇摘要。优先综合共同结论、分歧和边界，再列必要引用。
- 文献不足时缩小主张并记录待核验项，不用新文献填补叙事空缺。

### 主题之间的衔接

每个主题结尾应留下一个能被下一主题接住的缺口：

- “该路线主要解决了……，在……条件下的解释仍不完整。”
- “这一结果支持……，其在……条件下的稳定性仍待核验。”
- “因此，下一步需要从……机制/边界重新考察……”

这样可以把多个主题写成一条研究脉络，而不是几个互不相干的文献摘要。

## 3. 科学问题与科学假设

本节紧接研究现状、位于小结之前。它不是研究方案的压缩版，而是把“研究现状中的不足”讲成一条有因果关系的叙述：已有认识推进到哪里，哪一个关键关系仍未解释，为什么这个未知值得单独提出，以及本项目的切入点为何能形成可证伪的预测。科学问题可以在段末用疑问句明确收束，也可以先用连续叙述铺垫后再明确点出；科学假设随后解释预期机制或关系，不要求另起编号列表。

### 瓶颈 → 约束 → 问题 → 假设

这是内部构思工具，不是成稿模板。先用它检查逻辑，再把映射改写成连贯段落；不要把下面的标签、序号或箭头直接交给读者：

```text
瓶颈 1：现有解释依赖条件 A
约束 1：在条件 A 受限时
瓶颈 2：机制 B 缺少因果证据
约束 2：在机制 B 未明确时
核心未知：在约束 1、2 下，X 的 Y 性质为何、何时能够保持？
科学问题：在什么条件下，X 的 Y 性质能够跨越约束 1、2 保持，并由何种关系解释？
科学假设：如果机制 P 是关键限制，那么引入与 P 对应的表征/切入点后，X 将在约束 1、2 下呈现可观察的 Y 关系；这里的 Y 若指表征稳定性，不延伸为临床获益。
```

### 叙事优先的写法

成熟的立项依据通常不是把问题拆成多个编号任务，而是让读者先理解“为什么现有认识还不够”。可以按下面的顺序写成一个或两个自然段：

1. 回收研究现状中最重要的共同认识，并指出它在哪个条件变化后失去解释力；
2. 说明这个缺口造成的科学后果，避免直接跳到“本项目将检验……”；
3. 用一个核心问题把未知关系、机制或边界说清楚；若确有两个不可合并的未知，说明二者的因果或依赖关系，不要只并列编号；
4. 从项目切入点解释假设为何合理，再给出一个可以被支持或推翻的预测；模型、数据划分和评价指标只保留会改变科学解释的最少信息，详细方案后置。

例如，不要写成：

```text
R1：检验结构稳定性；R2：检验外部一致性；R3：检验新样本外推。
H1：模型在留出队列达到指标 A；H2：方法 B 优于方法 C；并进行折叠、调参和敏感性分析。
```

可以改写为：

```text
现有研究能够在生成队列中描述样本关系，却尚不能说明这些关系在队列构成和观测平台改变后是否仍代表同一生物学状态。真正需要回答的不是某一种模型能否复现原有标签，而是哪些关系具有跨队列的可重复性，以及这种重复性在什么条件下可以外推到新样本。基于这一缺口，本项目提出：若相对关系确实承载了比绝对表达尺度更稳定的生物学信息，那么以该关系为基础构建的表征应能在外部队列中保持与独立生物学参照一致的结构；若这一预测不成立，则可据此界定其适用边界。
```

这类写法仍然可证伪，但把“未知—理由—切入点—预测”交代完整，读者看到的是科学判断而不是验收协议。

叙述的深度来自解释现有证据之间的张力，而不是增加术语、任务或指标。至少要说清：已有结果在哪个条件下成立；条件改变后，哪一种解释会失效或彼此难以区分；项目切入点提供了什么新的观察角度；若假设成立，认识会推进到哪里。若材料只支持相关性，就把假设写成对关系稳定性或机制线索的预测，不要用“机制阐明”“临床价值确立”等更大的结论替代缺失证据。

### 科学问题的判定

好的科学问题：

- 指向明确的认知缺口，而不是泛泛问“如何提高性能”；
- 追问是什么、为什么、遵循什么规律或在什么条件下成立；
- 能由研究设计回答，答案又不是显然的；
- 问题中的约束都在前文出现过，术语与全文一致。

推荐句式（按材料改写，不要机械套用）：

- 在约束 A、B、C 下，X 的 Y 性质为何能够/不能保持？
- 什么条件下 X 的 Y 性质成立？
- 条件 A 变化时，X 的 Y 是否稳定、可迁移或可泛化？
- 现有证据所揭示的 X—Y 关系，是否代表同一机制，还是由条件 A 诱导的表面相关？

避免把问题写成“R1/R2/R3”“本项目依次检验……”或“能否构建/开发/实现 XXX”“本项目拟建立 XXX 以达到 XXX”；前两类是验证协议，后两类是研究目标或工程任务。

### 科学假设的判定

假设使用陈述句，解释“为什么会这样”并预测“将是什么或会发生什么”，不要把验证方式写进句子。可用：

```text
[核心机制/表征] 是 [现象/关系] 在约束 [A] 下仍能保持的原因；因此，引入 [切入点] 后，
[对象] 将呈现 [可观察、可反驳的关系或性质]。
```

写完后逐项检查：问题是否由前文缺口推导出来？假设是否解释了问题而不是重复项目目标？预测是否能被材料允许的观察推翻？是否把“在外部队列中验证”“通过实验验证”、模型结构、折叠和指标误写成假设本身？除非研究确实包含彼此独立的机制分支，不要把假设编号为 H1/H2。

理论、混合和工程导向只改变证据重心：理论项目强调定理、界、收敛性、反例或统一框架；机制项目强调因果链和跨尺度表征；工程项目强调约束、基线、指标和迁移边界，但都要保留可证伪的问题—假设关系。

## 4. 小结

小结通常用一段完成四步：

1. 压缩现状已经取得的主要认识；
2. 重申最关键的缺口和科学问题/假设；
3. 用与证据强度相称的方式放入前期工作，说明它为什么支持项目切入；
4. 用一句话衔接后续研究内容。

切入点应写成相对现有工作的实质增量，例如新表征、新机制、新方法学、统一框架或可证明理论。软件、平台和原型可以作为实现载体，但不要替代理论或科学贡献。详细目标、技术路线、主验证场景、判定规则和风险处理放到后续章节。

## 段落和句子的实用技巧

### 一个段落只推进一个判断

推荐使用“**主张 → 证据 → 解释 → 缺口**”四步。段首先告诉读者本段要判断什么，中间给证据和限定，段尾说明这组证据为什么仍不足。不要在同一段同时引入新对象、总结全文和提出项目方案。

### 事实、解释和推断分层

- 事实：已有研究观察到什么；
- 解释：这些结果支持哪种机制或理论；
- 推断：在什么边界内可以得出什么结论；
- 缺口：哪一步仍没有证据。

用“表明、提示、支持、尚不能说明、仅在……条件下成立”等词标出证据强度，避免把相关性写成因果性。

### 用可比较的语言替代空泛评价

把“效果好、明显提升、国际领先、填补空白”改成“相对谁、在什么对象/条件下、以什么指标、达到什么范围”。没有可靠数字时，写清适用范围、证据类型和未解决边界，不虚构量化结果。

### 保持术语和指代稳定

对象名称、缩写、指标和“该机制/这一现象”的指代应前后一致。首次出现的新概念给出最小界定；一句话中不要连续堆叠多个抽象名词。润色时保留事实、限定、引用、标签和 LaTeX 结构。

### 用过渡句显示研究脉络

段落之间明确“已有认识 → 新限制 → 下一问题”的关系；少用没有逻辑功能的“此外、同时、综上”。每个转折词都应能回答：是补充证据、比较路线、引出限制，还是收束到科学问题？

## 交稿前的五个评审问题

1. 开头是否在有限篇幅内说清研究对象、重要性和真正卡点？
2. 现状是否按问题或路线综合证据，而不是按作者和年份堆叠？
3. 每个关键瓶颈是否都映射到了科学问题的约束？
4. 科学假设是否给出可证伪的预测，并覆盖关键约束而没有写成验证方案？
5. 小结中的项目切入点是否体现实质科学增量，并自然引到后续研究内容？
