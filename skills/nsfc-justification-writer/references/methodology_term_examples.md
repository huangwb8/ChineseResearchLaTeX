# 方法学术语误用对比示例

> 立项依据里方法术语只作背景或验证手段，不能抢走科学问题/理论缺口主线。

## 核心规则

- 错误主线：方法术语 → 性能指标 → 工程目标
- 正确主线：科学问题/理论缺口 → 假说 → 验证方式

## 四类高频误用

### 1. 研究意义

- 错：以“深度学习/CNN/Transformer 发展很快”开头。
- 对：以关键机制未阐明、统一表征缺失或认知缺口开头。

### 2. 研究现状中的不足

- 错：只说准确率低、过拟合、诊断效能差。
- 对：指出假设过强、理论界不紧、框架不统一或因果链不清。

### 3. “科学问题与科学假设”小节

- 错：写成“开发一个系统/算法/平台”。
- 对：写成“通过 XXX 可以证明/阐明/统一 YYY”。

### 4. 小结中的项目切入点

- 错：交付物是软件、平台、工具。
- 对：交付物是理论、定理、方法学或统一框架。

## 快速自检

1. 段落主句主语是科学问题/假说/理论空白吗？
2. 删除方法术语后段落仍成立吗？
3. 本段回答“为什么做”还是“准备怎么做”？
