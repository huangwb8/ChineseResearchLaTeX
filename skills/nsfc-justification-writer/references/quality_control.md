# 质量控制

宿主 AI 负责语义判断，Python 负责确定性安全检查。写作任务完成两者后写入，审查任务仅交付诊断与建议。

## 诊断与语义复核

先说明任务类型、核心主张与论证主线；重要发现分为“必须修复、建议优化、可以保留”，列出位置、依据和影响。润色以局部保真改动为主；结构合理时明确保留，不以改动量证明工作价值。

| 复核对象 | 判断依据 |
| --- | --- |
| 事实与公允比较 | 先承认已有贡献，再讨论直接相关的限制；区分已考察但未解决、尚未研究或评价、明确条件下不能解决。未见报道不能证明首次或空白。 |
| 论证闭环 | 现状缺口是否解释核心未知，项目切入点为何支持可证伪预测；科学问题不被编号任务或评价协议替代。 |
| 前期证据 | 支持假设的关键观察是否在假设之前或紧邻假设；团队结果、外部研究、可行性基础与探索线索是否区分。缺少前期结果不强加段落。 |
| 科学主张 | 因果、机制、对象、范围、假设是否有无依据变化；“证明→提示”“导致→相关”也须核对依据和既有授权。 |
| 结构与篇幅 | 默认内容链是否发挥论证功能；段数、比例、标题仅为建议，必要证据、限定、引用和合理原有结构优先。 |
| 章节边界与学科适配 | 目标、技术路线、终点、阈值和风险处理不成为主线；方法学课题可研究可识别性、收敛性、误差界及泛化条件，不强套生物机制。 |
| 表达与自然度 | 术语、缩写、指代和衔接清楚；合并重复限定，保留所有影响科学解释的条件，必要时拆句、分段。仅审查用的信息不挤占正文。 |
| 受保护内容 | 句段移动后，引用、数学表达、标签和数值保持原意并随主张迁移；编译成功不证明科学保真。 |

### 科学主张与待决段落

措辞压缩、澄清指代以及不改变科学关系的重排可直接修订，重要调整说明理由。实质变更须核对证据和已有授权：依据明确且在授权范围内的纠错可执行并说明；未获相关授权或材料不足时仅给候选建议，说明影响和未采用状态。

待决主张使段落不能可信定稿时，保留该段原文、指出问题，完成其余可保真修订。不能以保守措辞暗换核心主张，不能把候选解释当作作者确认，也不能宣称含待决段落的全文可直接使用。已有授权无需再次确认，普通措辞无需逐项询问。

### 引用的三个核验层次

1. **bibkey 存在**：项目 `.bib` 中有对应条目，只证明可定位。
2. **文献信息可核验**：题目、作者、年份、DOI 等与可查来源相符，不等于支持正文。
3. **文献支持具体主张**：读到足够文献内容，核对对象、研究条件、结果与正文断言的关系。

逐项说明实际完成层次。只有条目或摘要不足以判断时，明确“支持性未核验”，不假装阅读全文。移动句段后重新检查引用与主张是否对应；缺失 bibkey 时不得仅为通过检查删除必要引用或改换科学主张。

## 面向作者的交付

正文提案与说明分开，说明统一为四类，避免重复一份审查报告：

```text
### 论证结构改进
- 重要调整及理由；或说明结构合理、予以保留。
### 学术表达改进
- 关键变化概述，不逐句罗列普通措辞。
### 科学歧义与证据缺口
- 位置、当前依据、不确定性、所需资料、实际完成的引用核验层次。
- 将证据等级、外推边界及保留限定的理由归入相关条目。
### 作者决策事项
- 位置、具体选项、对论证的影响、当前采用状态及待决段落。
```

简单润色可以简短交付，无问题类别写“未发现”。审查任务在这些类别内给诊断分级与建议；写作任务附完整正文、diff、备份和回滚信息。未解决的科学问题如实保留，不用“流程完成”替代成稿判断。

## 脚本安全检查

`scripts/run.py preview` 比较目标路径、引用 key、结构命令变化和正文 diff，默认检查通过后备份并写入；字数统计用 `wordcount` 或 `diagnose`。文献元数据及可选 DOI 联网校验用 `refs`；这些检查均不证明科学逻辑或文献支持性。

写入前确认目标在允许范围内，`main.tex`、配置、`.cls`、`.sty` 未改动，重要事实、必要限定、引用、标签和 LaTeX 结构保真。结构命令变化默认拒绝，授权后仍需显式 `--allow-structural-change` 并通过白名单。审查任务跳过默认 `preview`；确需检查候选 diff 时仅用 `--dry-run`。引用或安全检查未通过时保留原文件与提案，修复应保持科学含义。
