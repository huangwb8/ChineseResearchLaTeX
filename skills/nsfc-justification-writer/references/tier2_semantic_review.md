# Tier2 宿主 AI 语义审查规范

## 任务

读取宿主 AI 当前任务中已经确定的立项依据正文、Tier1 确定性诊断结果和必要的信息表。对正文执行语义审查。Tier2 由宿主 AI 直接完成；不要等待 Python responder，也不要用固定关键词命中或空结果替代审查。

## 必查内容

按正文实际内容自主判断重点，并至少覆盖以下关系：

- 领域价值、现实/理论必要性与研究对象是否清楚；
- 已有研究、引用证据与认知缺口是否匹配，是否把不可核验推断写成事实；
- “瓶颈/局限”是否转译为待解释的未知关系、机制、性质或适用边界；
- 科学问题是否是疑问句，科学假设是否是可证伪的预测性陈述；
- 是否把研究目标、技术路线、方法或验证终点误写成科学问题/假设；
- 假设前是否主要呈现领域事实、已有研究和认知缺口，项目方案是否仅在末端作简短衔接；
- 正文是否符合“研究意义—国内外研究现状及发展动态（按主题分块）—小结”的标准内容链，而不是把后续方案章节前置；
- “研究意义”是否混入详细前期工作、技术路线、模型比较、验证终点或研究目标；
- “研究现状及发展动态”是否完成“代表性证据—发展趋势—能力边界/缺口—项目切入点”，而不是重复研究意义或罗列论文；
- 前期工作是否在研究现状末端作为切入点桥梁，并使用与证据强度相称的措辞；
- 科学问题和假设是否作为现状末端的论证要素，而非被误写成主验证场景、总体目标或技术路线；
- 主验证场景、排除标准、主终点、比较基线、预设阈值、统计/模型锁定规则和风险处理是否错误地形成了立项依据章节；
- 术语、缩写和新概念是否首次定义且前后一致；
- 长句层级、指代、抽象名词、段落衔接和修饰语是否影响专业读者理解；
- “国际领先”“国内首次”“填补空白”等绝对化或夸大表述是否有可核验边界。

## 保真约束

- 不新增事实、实验结果、文献、DOI、研究对象细节或绝对化结论；
- 保留已核验事实、必要限定、引用命令、标签和 LaTeX 结构；
- 不因术语密度或必要限定而强行科普化；
- 无法在不改变科学含义的情况下改写时，保留原句，报告风险和保守处理依据；继续完成流程，不等待作者确认。

## 输出格式

输出 Markdown，供宿主 AI 在自动写入前自检：

```text
## Tier2 语义审查
状态：completed

### 逻辑问题
- 位置/原句特征：
  障碍：
  影响：
  保真改法：

### 术语与概念
- ...

### 证据与可核验性
- ...

### 专业可读性
- 位置/原句特征：
  障碍：
  影响：
  保真改法：

### 章节边界
- 句子/段落位置：...
  当前职责：...
  建议归属：研究意义 / 研究现状及发展动态 / 小结 / 研究内容 / 研究基础
  调整理由：...

### 优先修改建议
1. ...
```

章节边界项不是固定关键词命中结果。应结合标题、段落位置、证据类型和句子承担的功能作出人工可解释判断。标准立项依据通常只需要研究意义、研究现状及发展动态和小结三个内容层；主题性小标题可嵌套在研究现状内。若建议跨小节移动，先列出章节级提案（保留、后移、合并或拆分及其理由），再生成正文 diff；如果发现研究目标、主验证场景、判定规则或总体研究思路，应建议移至研究内容/研究方案/研究基础，而不是新建立项依据小节。

若正文不存在、范围不明确或材料不足，状态写为 `needs_input` 并列出缺口，同时基于可用上下文生成最小保守版本；不要臆造审查结论，也不要暂停等待输入。审查完成后直接生成正文 diff 并按自动模式写入，默认保留备份。
