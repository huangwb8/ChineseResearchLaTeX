# 查新判定指南

在低成本价值筛选后阅读。拟保留研究候选必须调用 `research-topic-extractor` 提取 topic、5–10 个英文关键词和 2–5 个核心问题，再调用 `research-literature-review` 的 Premium 档。每个依赖使用同一任务根下自己的 Skill 目录；`research-idea/novelty/Cx/` 保存判定与相对来源。

## 两层比较

先比较问题、解释或预测是否已被等价回答，再比较拟增加的条件为何可能改变已有结论。优先检索最近且最可能否定新意的工作，再补同义问题、相邻方法和适用边界。旧方法已经能回答问题时，协议组合更全不证明创新。

| 最近工作 | 共同问题 | 已有答案及条件 | 剩余未知 | 差异的科学意义 | 未确认等价性 |
| --- | --- | --- | --- | --- | --- |
| 稳定 R 编号及全文定位 | 不只比较术语 | 区分测量/对象/条件 | 证据支持的空白 | 改变何种认识或决策 | 全文/方法缺失等 |

复用本轮精读和定位，减少重复解释；仍须满足 Premium 依赖的实际交付标准。全文无法取得时，结论收缩到可读证据，不用检索数量、档位名称或“未搜到”代替新颖性判断。

## 判定与执行状态分开

- **未研究**：在明确检索范围内未发现直接或等价回答，已检查最近反方证据；只能作有边界的查新结论，不能证明全球空白。
- **部分研究但关键缺口存在**：已有答案不足以覆盖有科学意义的边界，拟研究能区分解释或改变认识。对象/尺度/条件不同本身不够。
- **已充分研究**：已有高质量研究直接回答问题、检验等价假设，或只是在换词重复；淘汰或实质重构。重要复现需重新论证其问题与价值，不能自动承诺发表价值。
- **未定**：直接近邻全文/关键条件无法确认，或必要执行尚未完成；不能进入正式推荐。

科学问题或假设实质改写后重新查新。全部淘汰按主流程进行有限重新探索；既不能无限生成，也不能将资料不足写成无合格候选。

## 最小判定记录

每个拟保留候选保存 `novelty-decision.json`，字段如下（值是填写说明，不可当作已完成证据）：

```json
{
  "candidate_id": "C1",
  "execution_status": "complete / incomplete / not_required",
  "novelty_status": "未研究 / 部分研究但关键缺口存在 / 已充分研究 / 未定",
  "direct_answer": "已有答案及适用条件",
  "equivalent_hypothesis_tested": "等价性判断和待确认部分",
  "key_gap": "证据支持的剩余未知",
  "scientific_delta": "差异为什么改变认识或决策",
  "nearest_work": [{"ref": "R1", "comparison": "共同问题、已有答案、差异及全文定位"}],
  "source_refs": ["可复核的本轮查新来源"],
  "decision": "保留 / 实质重构 / 工程事项 / 淘汰 / 待补证据"
}
```

价值筛选已经足以淘汰的工程/平凡候选无需完整查新，但保留淘汰依据、反方证据和 not_required 理由。`novelty` 阶段证据角色仍必需；零候选时用覆盖所有淘汰项的汇总。若任何关键淘汰理由依赖尚不可得的文献或未执行核验，业务结论为 insufficient。
