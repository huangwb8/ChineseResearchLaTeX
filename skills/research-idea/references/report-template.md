# 研究想法报告模板

新报告使用下列契约；配置为状态、章节与字段的唯一机器来源。花括号是写作提示，提交前替换为实质内容。首节一页以内，先说明问题为何重要，再展开 map 和比较。正式报告不引用隐藏工作区。

```markdown
---
report_contract: research-idea-report-v2
outcome: recommended
exploration: complete
novelty: complete
review: complete
---
# {研究主题}

## 结论与研究目标

{明确写“有可推荐候选”“当前范围内无合格候选”或“证据不足，暂不能推荐”。说明研究贡献、服务的问题/决策、已确认资源与未知条件；概括价值、证据链、最近工作差异与确定程度。}

## 研究脉络 map 摘要

{复用研究综合指南的研究线比较、关系与演化、研究机会三部分，保留时间线。区分来源支持的关系与待验证综合判断。}

<a id="o1"></a>
**O1**：{未解释现象或重要边界、已有解释不足、辨别观察、最近反方证据；引用 [R1](#r1)。}

<a id="r1"></a>
**R1**：{论文标题、稳定 DOI/URL、年份、原文节/图/页定位、全文或摘要证据深度。}

## 候选评估

### C1：{短标题}

**科学问题**：{具体问题}

**可证伪科学假设**：{条件、预测及可能推翻它的观察}

**关键预测**：{如何区分可能答案，简单基线预期如何}

**反证路径**：{失败后排除什么解释}

**价值与非平凡性**：{知识增量/决策影响，常规解释为何不足}

**最近工作与实质增量**：{共同问题、已有答案、剩余未知、新条件为何重要、未确认等价性；引用 R 编号}

**最强替代方向**：{同样投入还能研究什么，保留本项的理由，改变排序的条件}

**判断可信度与近期投入**：{证据稳健/暂定部分；已具备/明确没有/未知资源；条件性投入建议}

**脉络依据**：[O1](#o1)，[R1](#r1)；{说明推导关系}

**查新结论**：部分研究但关键缺口存在；{实际 Premium 查新范围、来源和保留理由}

## 查新摘要

{按候选给最近工作比较、实际执行的 Premium 查询范围与覆盖限制。未执行、不完整与完成分别说明，不能靠 Premium 字样或论文数量证明新颖性。}

## 推荐与投入排序

{分别列科学价值优先级和近期投入建议，附判断可信度、最强备选、并列/分歧、资源变化后的选择。无需加权总分；一个候选也合法。}

## 风险与下一步

{最大关键未知；最小辨别动作；何种观察改变去留。完整方案交给 research-plan。}
```

候选数量不等于初始探索数量；仅保留项使用 `### C1` 或 `### 候选 1` 标题，每项完整表达字段，不能写“同上”。O/R 编号稳定，引用使用 `[O1](#o1)` / `[R1](#r1)`，并在报告中提供对应显式 HTML 锚点与实质说明。无需强制绘图。

## 无合格候选分支

frontmatter 使用 `outcome: no_qualified`、`exploration: complete`、`review: complete`。`novelty` 只能为 `complete`，或有价值筛选证据支持的 `not_required`。删除推荐章节与所有保留候选标题，在“候选评估”中用淘汰表保留原 C 编号、O/R 依据和处置；不能凭文献受限给此结论。补充：

```markdown
## 淘汰理由与重启条件

**评估范围**：{实际主题、证据与资源边界，不代表全领域}

**淘汰依据**：{每个候选为何平凡/重复/不产生重要认识，引用 O/R 锚点；审查的异议如何处理}

**重新探索**：{失败原因在构造还是 map；新证据/新视角、一次重新探索结果或用户预算的明确限制}

**重启条件**：{哪些新观察/资源/问题变化值得重启}
```

若无需完整查新，在“查新摘要”增加 `**免查新依据**：{支持价值筛选淘汰的文献/逻辑与适用范围}`。它不能替代拟推荐候选的 Premium，也不能免除探索与独立复核。

## 证据不足分支

frontmatter 使用 `outcome: insufficient`，按真实情况给三个执行状态填 `complete` 或 `incomplete`（价值筛选足以说明无需查新时可给 novelty 填 `not_required` 并说明）。“候选评估”可以仅说明无法形成候选；如列探索候选仍须完整表达结构，查新结论可以写“未定”。不得列为正式推荐。替换推荐章节为：

```markdown
## 证据缺口与恢复位置

**关键缺口**：{缺少的资料、近邻全文或尚未执行的工作；影响哪个判断}

**恢复位置**：{当前业务阶段、应先补什么、完成何种核验后可继续；用可读说明，不泄露运行路径}
```

格式合格的阶段性评估可交付，但 `completion_eligible` 为 false，运行保持最近阶段，不能声明 completed。查新结果“未定”不能转述为“未研究”。

## 历史兼容

没有新 frontmatter 的旧报告沿用旧标题与数量规则进行结构读取，并返回 legacy 警告；不能被用于新运行完成。保留原历史文件和事件。需要按新标准继续时创建新 run，将旧资料作为待重新核验的引用，不改写历史结论。
