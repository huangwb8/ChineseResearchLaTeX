# 独立审查参考

每轮调用 parallel-vibe 前读取。轮数和每轮人数取初始化设置，默认 3 轮、每轮 3 人；外层串行，每轮内部独立读取事实与证据，不互读草稿。首轮不注入主 Agent 偏好的候选。上一轮事实修正保留，推荐意见可以推翻。

| 轮次 | 核心任务 | 本轮必须新增的判断 |
| --- | --- | --- |
| 第一轮 | 即使完全成功是否值得研究？ | 价值否决、平凡解释、同样投入的最强替代方向及依据 |
| 第二轮 | 解释和预测能否区分可能答案？ | 定义保证的假设、关键反例、简单/强基线是否足够、最近工作覆盖、实质重构 |
| 第三轮 | 在最强备选前重新选择 | 科学价值与近期投入分别排序、资源变化敏感性、外推边界、最终去留 |

用户改动轮数时将三类任务分配到实际轮次，轮数较少合并任务，较多则针对未解问题增加审查；不伪造已执行次数。

## 每个审查者的输入

研究目标与确认资源、map、候选、最近工作比较及真实查新来源、证据深度、上一轮事实修正与争议、当前轮次任务。不能只读 summary 代替关键论文依据。候选为空时审查淘汰证据、被遗漏的替代方向、重新探索是否实质发生以及重启条件。

## 简短输出契约

记录本轮新增发现及来源、影响哪个候选及处置、最强反例或替代方向、必要改写和未决分歧；说明检查后未改稿的具体理由。只复述上轮或确认字节相同不算新判断。

假设由定义保证、简单方法已足够或成功/失败均无知识增量时，应提出实质重构/淘汰；重要复现、测量改进和负结果仍按重要性与证据判断。资源未知不等于不具备，容易实施不等于科学价值高。

## 汇总与返回路径

主 Agent 按论证和反例判断，不按多数票决定真伪。需要新文献回文献步骤；实质改变问题/假设回 candidates 并重新查新；需要新候选按有限探索预算执行。不能靠免责声明消化缺陷。保存各轮新增发现和成本，草稿不变可以合理，但仍须有本轮独立判断证据。
