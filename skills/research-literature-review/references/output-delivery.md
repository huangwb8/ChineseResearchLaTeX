# 综述正式交付规范

本文件规定用户可见的最终目录。写作准备时确认路径，导出、发布及最终交付前必须读取并执行；内部工作区继续遵循 `SKILL.md` 的输出管理规则。

## 统一目录

标准综述包采用以下结构，根目录中的文件只能是综述正文的三种格式：

```text
{交付目录}/
├── {主题}_review.docx
├── {主题}_review.pdf
├── {主题}_review.tex
├── references/
│   └── {主题}_参考文献.bib
├── qc/
│   ├── {主题}_工作条件.md
│   └── {主题}_验证报告.md
└── materials/                         # 有实际材料时才创建
    ├── 阅读地图与研究热度.md           # 示例，不是必做清单
    ├── 研究热度_原始统计.csv
    ├── 研究热度.png
    └── 研究热度.pdf
```

`references/` 保存正式引用的 BibTeX 书目；`qc/` 保存工作条件、检索和证据边界、实际验证结果及未验证项。成品根目录不新增 README、目录索引或其它说明，必要的使用说明和材料导航写入已有工作条件。

正文使用的图片、表格片段、子 TeX 和用户指定的本地自定义资源也归入 `materials/`，可按用途设子目录。Skill 内置 BST 仍直接引用当前宿主机资源，系统包和样式由 TeX 发行版提供，不复制入成品。

## materials 的取舍

AI 可以自主保留对读者有实际价值的辅助材料，例如经典研究阅读顺序、研究脉络、发文活跃度统计或补充比较表。它们是可选附件，不要求每次生成，不因存在 `materials/` 而扩大任务或凑材料。正文编译依赖放入这里后属于必需资源，应与可选导读在工作条件中说明用途。

做了额外分析并决定交付时，保留理解和复核它所需的最小完整材料：解释、数据来源与口径、实际用到的数据和图像。例如交付热度图时，配套记录检索式、数据库、检索日期、年度计数和局限；发文量不能替代证据强度、临床价值或疗效判断。PNG 与 PDF 是否同时保留由实际阅读、编辑或分享用途决定。

`materials/` 不作为内部文件的兜底目录。候选池、评分、选文审计、证据卡、字数预算、流水线状态、临时脚本、缓存和编译日志留在任务工作区；不把整个运行目录复制成附件。公开辅助材料也不得包含凭据、私有 Prompt 或隐私。

## 路径与发布

- 主稿从交付根目录解析资源，例如 `\bibliography{references/{主题}_参考文献}`、`\includegraphics{materials/figures/图名.png}`。正文片段中的依赖也按主稿根目录解析；不要依赖用户机器上的业务文件绝对路径。
- `materials/` 内的 Markdown、数据和图片保留相互之间的相对路径。`qc/` 中的导航用 `../references/`、`../materials/` 和 `../{主题}_review.pdf`，不能沿用文件归类前的平铺链接。交付前核对本地链接、图像及 TeX 依赖。
- 内部暂存布局不变：PDF/Word 在 `output/deliverables/`，源码、书目和质检在其 `supporting/`；AI 决定保留的辅助材料先整理进 `supporting/materials/`。这一步是显式选择，不自动扫描其它任务文件。
- `--publish-dir` 将暂存内容归类为上述结构，并同步改写交付副本中的静态 TeX 资源路径；不修改源稿。发布器随包复制 `supporting/materials/` 中整理好的附件，并保留目录关系。路径冲突、缺依赖、符号链接和越界资源在写入前拒绝。
- 默认完整包必须具备三种正文格式、书目和两份质检说明。`--readers-only` 是显式例外，只交付根目录的 PDF/Word，不包含源码、质检和附件；直接 Python API 的轻量默认保持一致。`novelty-check` 在选文阶段结束，不套用完整文稿包要求。

## 验收与历史兼容

检查根目录文件集合、分类位置、相对链接、必需文件和资源完整性；路径改写后验证 TeX 可解析并按风险重新编译。结构通过不代表论断核验、目视检查或证据审查已完成，实际检查与限制写入 `qc/`。

旧版平铺目录不再是标准输出；恢复旧运行仍可读取历史暂存布局，但应发布到新的目标目录。不得自动迁移、删除或覆盖用户已有成品；即使使用覆盖选项，目录中存在本次发布集合之外的文件仍应停止。现有引用旧成品路径的外部工具需按新目录更新。
