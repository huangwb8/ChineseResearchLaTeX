# AI 相关性评分、数据抽取与选文

评分阶段读取本文件。宿主 AI 直接阅读 canonical 候选的标题与完整可用摘要，生成评分记录；没有关键词脚本评分后备。评分不调用另一套检索或去重流程。

## 输入与判断边界

使用主题、核心问题、范围，以及论文的 `title`、`abstract`、`year`、`venue`、`authors`、`doi`。元数据缺失时保留未知；摘要未提供的方法、数字或局限不得补猜。保留 canonical 记录与来源字段，将评分和抽取结果附加到对应记录，不用评分 JSON 覆盖原论文信息。

相关性只表示论文对当前问题的适用程度，不代表偏倚风险、证据等级或推荐强度。相反结果、阴性结果及采用不同方法回答相同问题的研究也可能高度相关；预印本与正式论文按同一尺度评分，发表状态另列。

分数范围读取 `config.yaml:scoring.score_scale`（默认 1–10），选文门槛读取 `selection.minimum_score`（默认 5）。不预设高、中、低分比例，不依据期刊声望或关键词重叠次数替代语义判断。

## 评分 Prompt

```text
请评估论文对当前研究问题的相关性，并输出严格 JSON。

研究主题：{topic}
核心问题：{core_question}
时间及纳入范围：{scope}
论文信息：{paper_record}
评分范围：{score_scale}
相关性门槛：{minimum_score}

综合判断研究对象/任务、方法/机制、数据/人群/场景与应用价值；按主题调整各维度的意义。不适用或无法确认的维度写“不适用”或“未知”。

默认 1–10 分尺度：
- 9–10：直接回答核心问题，或构成必须比较的近邻、反方或边界证据。
- 7–8.9：高度相关，但对象、方法或场景有需说明的差异。
- 5–6.9：提供相关背景、方法或间接支持，需限制外推。
- 3–4.9：仅局部概念或技术重叠。
- 1–2.9：与核心问题基本无关。

仅当分数达到当前 minimum_score 时填写 subtopic，否则填空字符串。
在整批候选中复用稳定的子主题名称；默认围绕 3–7 个有证据支撑的问题组织，不按技术名称或标题关键词机械分组。
缺少摘要时说明判断仅基于标题，不声称完成摘要或全文核验。

提取研究设计、关键结果与局限。数值仅在原摘要可确认时保留；缺失信息填“未明确提及”。
```

输出字段示例（内容需据实际论文填写）：

```json
{
  "doi": "{doi}",
  "score": 7.0,
  "subtopic": "{达到门槛时填写的子主题}",
  "rationale": "{相关依据、差异与判断所依赖的资料范围}",
  "alignment": {
    "task": "完全匹配/部分匹配/不匹配/不适用/未知",
    "method": "完全匹配/部分匹配/不匹配/不适用/未知",
    "modality": "完全匹配/部分匹配/不匹配/不适用/未知"
  },
  "extraction": {
    "design": "{研究设计或方法}",
    "key_findings": "{可核实的关键结果}",
    "limitations": "{可核实的局限或未明确提及}"
  }
}
```

每篇一条，将上述字段并入原始记录后写入当前 run 的 `scored_papers.jsonl`（历史文件名以 runner 提示为准）。

## 子主题与选文

子主题围绕综述问题组织，默认与 3–7 个主体主题相衔接；发现重要异质性时保留区别，不强并所有 CNN、Transformer 或单例研究。评分阶段的分组是写作规划输入，最终结构由证据与问题共同决定；用户或期刊指定其它结构时同步调整检查参数。

`select_references.py` 负责确定性选文。标准综述仅将达到门槛且有可用摘要的记录纳入正式引用集合；摘要可用性阈值读取 `search.abstract_enrichment.min_abstract_chars`。不按候选库前 60–80% 截取，也不用低分或无摘要记录补足篇数。`target_refs` 是软预算，`max_refs` 是上限；合格记录不足时交付较小集合，在 `selection_rationale.yaml` 记录停止理由与缺口。

证据角色按内容标记为 `direct-neighbor`、`supporting`、`methodological`、`contradictory` 或 `boundary`；优先考虑直接近邻及反方证据，不能只因方法相似就视为直接支持。角色不替代相关性评分。需要显式标注时将 `evidence_role` 附加到评分记录；未标注的旧记录由选文脚本按 `supporting` 处理。

`novelty-check` 仅运行至选文；只有标题的记录可作为待升级线索保留并标记 `do_not_cite`，不能据此声称完成全文核查或纳入标准综述的正式引用。

## 交接检查

- 分数在当前范围内，理由与实际读到的资料相符，没有人为调整评分分布。
- 原始候选及来源字段保留，抽取中的研究身份、数字和结果方向可回到来源核对。
- 低于门槛的记录不分配子主题；资料不足与低相关性分别说明。
- 正式引用遵守门槛与摘要要求；软预算缺口如实记录。
- 写作阶段再读 [专家写作指南](expert-review-writing.md)，不把评分通过当作论断已核验。
