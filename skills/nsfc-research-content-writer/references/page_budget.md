# 篇幅规划

研究内容默认按 **12–15 页（含图表）** 组织；这是已确认的经验边界，除非用户明确要求，否则继续保留。具体数值以 `config.yaml:quality_contract` 为单一来源。原有纯文字 **12000–15000 字** 建议保留作辅助参考，不作为硬校验或实际页数换算公式。

按问题、任务、验证的必要性分配篇幅，图表占用真实版面。不要承诺插入大量图表通常不影响文字篇幅，不以固定字数凑页。总篇幅、字体和行距须核对当次申请指南及项目模板，不能把经验性建议写成普遍官方规定，也不缩小字体或行距挤内容。

本 Skill 不生成图。研究内容的技术路线图建议放章节开头；立项依据的机制图和研究基础的预实验图留在相应章节范围。

Python 仅报告去注释后的中文字符及英文/数字词单元，不等于排版字数或页数。确需核验时调用当前项目官方 Python 构建 wrapper，基于实际编译结果检查章节页数。无编译证据必须写明“尚未核验实际页数”，不能宣称已经满足页数范围。
