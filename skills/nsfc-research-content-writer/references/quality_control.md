# 质量控制与科学保真

## 按任务决定改动幅度

新写从材料建立方案；重构可重排已授权章节并解释理由；审查只读；润色保留成熟设计、结构和作者声音。先标必须修复、建议优化和可以保留，不能用改动量代表价值。

添加队列、改变主要终点、样本量、机制或关键实验都可能改变项目承诺。核对依据及已有授权；有授权就执行并解释，没有授权则保留待决原文，给出选项和影响。纯语言调整不逐句确认，也不反复申请已有许可。

## 三章关联复核

逐项追问：创新是否由研究内容中的具体设计和验证支持？是否把验证的独立性、因果解释或可部署性夸大了？年度里程碑是否覆盖全部任务，顺序是否符合数据、实验、证明和资源依赖，各年是否有明确交付？三章是否与立项依据的科学问题、研究基础中的真实条件一致？术语、指标定义、来源边界和缩写是否漂移？

局部任务也只读检查关联内容；发现影响时按授权同步或给建议。关联是语义判断，不能通过 S 编号匹配、关键词数量或固定机械分数证明。

## 适用时的验证检查

算法比较保持同数据、指标、划分与调参预算；按需要做模块消融、独立中心/时间/来源验证，写清“外部”的含义。个体、时间或批次划分及预处理拟合范围需避免测试信息泄漏。报告适当的效应量、区间、重复及方差，必要时考虑校准、噪声/缺失/偏移和失败样本。

机制研究重点是干预、救援与竞争解释；理论研究重点是条件、证明、反例和必要模拟。对照不总等于某个机器学习基线。不能为完善验证叙述补造数据、实验重复数或统计功效。

## 常见反模式

| 反模式 | 修订方向 |
| --- | --- |
| 首次、领先、填补空白等自我定性 | 核对证据；改为可审稿的相对差异，不因词表命中就判定虚假 |
| 堆方法却不说解决哪个未知 | 绑定研究问题、判断结果和必要比较 |
| 显著提升却不说明怎么判断 | 补已有依据支持的指标/结果与对照，不能编预期幅度 |
| 数据来源含糊 | 核对来源、边界、时间窗和可用条件，缺口说明留给作者 |
| 创新无任务支持，年度计划流水账 | 返回研究任务和依赖关系逐项复核 |
| 内部编号、规划表或验证菜单进入正文 | 自然叙述验证逻辑，清除工作流标签 |
| 用文字数代替实际页数 | 按篇幅规划并使用官方 wrapper 核验排版 |

## 完成检查

授权范围正确；合理内容保留；任务具有可判定结果、对照和验证来源；创新可理解、可对照、可验证；三年安排有依赖和交付；术语一致；没有虚构事实或暗换承诺；正文无内部规划标记。依据配置复核经验边界，数量不符先解释，不强行凑数。

文件层面核对角色集合、路径、禁写范围、引用 key、结构 diff、备份与恢复入口。引用 key 存在只说明可解析，不证明文献真实或支持该主张。没有编译就注明尚未核验实际页数；脚本通过不代替上述科学判断。
