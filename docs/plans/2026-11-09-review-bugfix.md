# research-literature-review 本地缺陷修复

## 范围与判断

核对本地 25 条记录，保留现有未提交的参考资料清理改动。重复记录按根因合并，已有修复通过当前回归确认后追加本地 resolution，不改原始报告。源码修改限于 review 及承担同名模块冲突的 search 查询接口；不更新系统安装副本、不公开上传。

## 实施顺序

1. 保存当前源码基线，记录报告 ID 与已有 resolution，运行现有回归。
2. 为仍存在的缺陷增加定向复现：配置只读边界、Unicode JSONL、系统 BST、预算档位、引用命令、禁止引用标记、元数据换行转义和查询模块隔离。
3. 最小修复：保持候选与输出路径隔离，只豁免 Skill 自带只读配置；查询实现使用唯一模块名并保留旧导入接口；系统 BST 按实际 TeX 搜索环境解析；标准选文遵守显式资格判断。
4. 验证历史修复：恢复 checkpoint、相对配置规范化、导出配置与模板传递、验证报告成功输出解析、评分入口清理。
5. 同步两项 Skill 的版本、README、执行规范与 CHANGELOG；复核上游结构和公共约束，记录 BAC 与本地 resolution。

## 验收

定向回归覆盖有效输入和失败路径，运行 review 原有测试及 search 契约回归；真实工具可用时验证系统 BST 编译与 PDF/Word 导出。结构检查不能证明学术内容质量；本任务不评价长篇综述的生成效果。任务材料统一存放于 `.bensz-api/task-20261109-2102-fix-review-bugs/`。
