# 综述交付目录规范实施计划

## 问题与目标

现在主稿、书目、质检说明和可选导读混在同一目录，用户难以一眼找到正文。调整后，打开任一综述目录都先看到三种正文格式；文献、质检和辅助材料各有固定位置，AI 仍可保留对读者有价值的补充内容。

## 改进方向与顺序

1. 在 Skill 的 `references/` 新增独立输出规范，定义根目录及 `references/`、`qc/`、`materials/` 的职责，区分正式辅助材料与内部过程文件。
2. 更新发布和目录检查入口：按新结构输出，并同步 TeX 的书目、图片和片段相对路径；保持内部运行布局及只读格式模式兼容。已有用户目录不自动迁移。
3. 同步 Skill 入口、README、配置版本与变更记录，完成定向发布回归和实际重编译。

## 完成标准

标准包根目录仅有正文 PDF、Word、TeX；Bib 位于 `references/`，工作条件和验证报告位于 `qc/`；可选材料和正文图表位于 `materials/`，原有内部中间产物不被带出。发布后 TeX 能解析归类后的资源，辅助材料内部链接可保持相对路径。缺文件、路径越界和目标冲突在写入前拒绝。

## 风险与兼容

正式目录路径属于公开输出变更，需明确迁移说明并提升 Skill 主版本。内部 `supporting/` 暂存布局不变；发布器只改写交付副本，不修改源文件。已有平铺成品通过新目标目录重发，不就地移动或覆盖。
